# Security Policy

## Supported Versions

Only the latest published version of `@thefehr/foundry-playwright` on npm is
supported. There are no maintained LTS/legacy branches.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for a suspected security
vulnerability.

Instead, use GitHub's private vulnerability reporting for this repository:

https://github.com/TheFehr/foundry-playwright/security/advisories/new

You should receive a response within a few days. If the vulnerability is
confirmed, a fix will be released and a GitHub Security Advisory published
once a patched version is available.
